## まなびサポート（算数・国語 学習支援アプリ）

小学生（1〜6年）向けの算数・国語ドリルと、獲得ポイントで育てる農場ゲームを、
ブラウザで遊べる Web アプリです。

### 起動方法

```bash
pip install -r requirements.txt
python run_study.py
```

ブラウザで http://127.0.0.1:8000 を開いてください。停止は `Ctrl + C` です。

> 起動はプロジェクトのルート（`README.md` があるフォルダ）で行ってください。
> `python study_app/main.py` や `python -m study_app.main` でも起動できます。
> `ImportError: attempted relative import with no known parent package` が出る場合は、
> `python run_study.py` または `python -m study_app.main` を使ってください。
>
> 記録の保存先を変えたい場合は環境変数 `STUDY_DB_PATH` に SQLite のパスを指定できます。

### できること

- 学年（小1〜小6）・教科（算数／国語）・ジャンル・問題数・むずかしさを指定して出題
- 算数: 計算、かけ算わり算、分数、小数、図形、単位、割合、円、平均などを自動生成
- 国語: 漢字の読み・画数・部首、ひらがな、ことばの意味、文法、ことわざ、文章読解
- 回答直後に正誤と解説を表示。間違えた問題は復習リストに残る
- **アカウント（ローカルプロフィール）**: なまえ＋4桁PINで作成。メール不要・外部送信なし
- **ポイント**: 正解 +10、間違えても参加点 +2、5問連続正解ごとに +5、
  クイズ達成 +10〜20、全問正解 +50、1日1回ログイン +5
- **レベル**: 100 pt ごとにレベルアップ（Lv.1 ひよこ → うさぎ → きつね → ライオン）
- ポイントは「**累計ポイント**」（レベル用・減らない）と「**使えるポイント**」（農場で使用）に分かれます
- ヘッダーに現在のアカウント・両方のポイント・レベル・連続正解を常時表示
- 同じ端末では前回のアカウントを自動選択し、切り替え時は PIN を確認します
- 結果画面で獲得ポイント、記録画面でポイントの内訳と履歴を確認可能
- 記録は端末内の SQLite（`study_app/data/progress.sqlite3`）のみ。アカウント情報も外部送信なし

### 🌱 農場ゲーム（ポイントの使い道）

画面上部の「📝 ドリル」「🌱 農場ゲーム」タブで切り替えられます。
ドリルで稼いだ「使えるポイント」を消費して、農場を少しずつ育てるゲームです。

| やり方 | 内容 |
|---|---|
| たねを植える | たねを選んで空き畑をクリック。作物は時間がたつと育つ（キャベツ30秒〜ひまわり180秒） |
| 収穫する | 育った畑をクリックすると売却ポイントを獲得。畑はまた空きになる |
| どうぶつを買う | にわとり・うさぎ・うしを購入。一定時間ごとに卵・にんじん・牛乳がとれる |
| たてものを買う | こや・いけ・かざぐるまを置いて農場をにぎやかにする |
| 畑をひろげる | 150 pt（以降 300, 450 pt…）で畑を3つずつ追加。最大18畑まで |

- 収穫・回収・購入・拡張で**農場EXP**がたまり、農場レベルも上がります
- 売却で得たポイントは「使えるポイント」「累計ポイント」両方に加算されるので、
  農場を回すほどドリルのレベルも伸びます
- 農場の状態はアカウントごとに保存され、画面は3秒ごとに自動更新されます（「🔄 更新」でも即時更新可）
- ポイントが足りない場合や、育つ前に収穫しようとすると、画面にメッセージが表示されます

### 問題の出典

- 漢字: 文部科学省「学年別漢字配当表」ベースの公開データを同梱
  （出典: スクールコンパス https://eleschool-compass.com/contents/kanji/kanji-data.php ）
- 文章・ことばの問題: 本アプリ用のオリジナル教材
- 算数: 数値を自動生成（著作物の複製なし）

著作権や利用規約が不明な問題集サイトからのスクレイピングは行わない設計です。
詳細は `study_app/data/ATTRIBUTION.md` を参照してください。
